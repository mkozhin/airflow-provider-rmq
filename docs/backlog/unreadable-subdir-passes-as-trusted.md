# Нечитаемый вложенный каталог проходит как доверенный скан и уносит подписки своего поддерева

**Симптом.** `_scan_subscriptions` собирает файлы через
`glob.glob(os.path.join(dags_folder, "**", "*.py"), recursive=True)`
(`airflow_provider_rmq/watcher/listener.py:1782-1784`). `glob` ловит `OSError` от
`os.scandir` каждого вложенного каталога и молча прекращает обход этого
поддерева. Нечитаемая вложенная директория просто исчезает из `current_files`, не
оставляя ни одной ошибки, которую скан мог бы увидеть.

Проверка читаемости в `_get_dags_folder` пробует `os.scandir` **только на
корне** (`listener.py:1750`) — она ловит `chmod 000 dags/`, но не
`chmod 000 dags/orders/`.

**Трасса.** В папке DAG'ов 40 файлов, из них 6 лежат в `dags/orders/`. На этот
каталог теряются права — деплой под другим пользователем, перемонтирование,
неудачная синхронизация. Скан перечисляет 34 файла из 40: доля читаемого выше
`_TRUSTED_SCAN_FRACTION` (`readable >= baseline * _TRUSTED_SCAN_FRACTION`,
`listener.py:1833`), перечисление признаётся доверенным, счётчик недоверия
обнуляется (`listener.py:1836`). Пути из `orders/` вычищаются из кэша
(`listener.py:1872-1880`), ключи шести подписок уходят из доверенного скана, считают
промахи и через `_ABSENT_GRACE_CYCLES + 1` циклов удаляются. Права возвращают —
скан пересоздаёт строки **включёнными**, включая ту, которую оператор выключил
кнопкой.

**Docstring обещает больше, чем делает код.** Docstring `_scan_subscriptions`
(`listener.py:1766-1772`) говорит, что вытеснение путей ждёт вердикта, «so a listing
that lost a subtree to a permission error leaves the previous parse of it intact».
Это верно только для перечисления, которое вердикт признал недоверенным, то есть
для поддерева больше половины папки. Доверенное перечисление вытесняет пути
потерянного поддерева в том же вызове, и прежний разбор не сохраняется. Читатель
docstring'а считает этот сценарий закрытым, а он открыт.

**Почему `worth: yes`.** Это путь ровно к тому дефекту, ради устранения которого
писан план `20260902-scan-miss-deletes-subscriptions`, и он не требует ни
таймаутов, ни двух шедулеров, ни гонок — только потерю прав на подкаталог, которая
держится несколько минут. Пропорциональное правило доверия его ловит лишь
частично: поддерево больше половины папки роняет долю читаемого и уводит
перечисление в недоверие вместе со всем остальным, а поддерево поменьше проходит
целиком.

**Что закрыло бы.** Узнать об этих `OSError` можно единственным способом —
собственным обходом, `os.walk(onerror=...)`. Он расходится с `glob` и по скрытым
именам (`.git` внутри папки DAG'ов попадает в обход), и по символическим ссылкам
на каталоги, которые `**` проходит, а `os.walk` по умолчанию нет. То есть замена
меняет состав перечисления на каждой установке, и делать её заодно с работой про
промахи скана было бы протаскиванием несвязанного изменения. Отдельной задачей —
уместно. Та же задача приводит docstring `_scan_subscriptions` в соответствие с
тем, что код гарантирует.

Смежное: [[scan-ignores-airflowignore]] — про то, *какие* файлы попадают в скан, и
там та же развилка про `list_py_file_paths` вместо `glob`; закрывать их разумно
одним заходом.
